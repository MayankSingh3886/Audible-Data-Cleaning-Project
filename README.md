# Audible-Data-Cleaning-Project
🎧 Audible Data Cleaning Project

📌 Project Overview

This project focuses on cleaning and preprocessing Audible audiobook data to make it accurate, consistent, and ready for analysis.

The dataset contains information about audiobooks available on Audible, including titles, authors, narrators, ratings, prices, durations, and other attributes. The main goal of this project is to identify and handle issues such as missing values, duplicate records, inconsistent formats, and incorrect data types.

🎯 Objectives
Clean and preprocess the Audible dataset.
Identify and handle missing values.
Remove duplicate records.
Standardize text and categorical data.
Convert columns into appropriate data types.
Clean and standardize audiobook duration and price information.
Prepare the dataset for further Exploratory Data Analysis (EDA) and visualization.

🛠️ Technologies Used
Excel Power Query

📊 Dataset

The dataset contains information related to Audible audiobooks, such as:

Book title
Author
Narrator
Rating
Number of ratings/reviews
Price
Duration
Genre/category
Release information
